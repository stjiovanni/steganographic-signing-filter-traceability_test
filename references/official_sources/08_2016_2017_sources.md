# 2016-2017 Peer-Reviewed Source Checks

The DOI in each record resolves to the official publisher or proceedings record. These are archival publications, not preprints, blogs, GitHub pages, or unofficial copies.

## Ansari, Pant and Ahn (2016)

**Citation:** Ansari, I. A., Pant, M. and Ahn, C. W. (2016) 'Artificial bee colony optimized robust-reversible image watermarking', *Multimedia Tools and Applications*, 76(17), pp. 18001-18025.

**DOI / official publisher:** https://doi.org/10.1007/s11042-016-3680-z

**Project relevance:** Optimization and reversible recovery add dimensions absent from the current fixed-strength DCT baseline.

**Implementable gap:** Add reversible embedding, exact host recovery, and an optimization sweep; report BER, PSNR, and reversibility under the existing transform suite.

## Kulkarni, Mulani and Mane (2016)

**Citation:** Kulkarni, P. R., Mulani, A. O. and Mane, P. B. (2016) 'Robust Invisible Watermarking for Image Authentication', *Emerging Trends in Electrical, Communications and Information Technologies*, pp. 193-200.

**DOI / official publisher:** https://doi.org/10.1007/978-981-10-1540-3_20

**Project relevance:** Authentication framing supports evaluating integrity separately from simple payload recovery.

**Implementable gap:** Add tamper localisation or an integrity map and evaluate it independently from bit accuracy.

## Pardhu and Perli (2016)

**Citation:** Pardhu, T. and Perli, B. R. (2016) 'Digital image watermarking in frequency domain', *2016 International Conference on Communication and Signal Processing (ICCSP)*, pp. 208-211.

**DOI / official proceedings:** https://doi.org/10.1109/ICCSP.2016.7754123

**Project relevance:** Provides a published frequency-domain comparator for the project DCT baseline.

**Implementable gap:** Compare a second frequency-domain embedding rule over a strength sweep and plot robustness against visual distortion.

## Ansari, Pant and Ahn (2017)

**Citation:** Ansari, I. A., Pant, M. and Ahn, C. W. (2017) 'Secured and Optimized Robust Image Watermarking Scheme', *Arabian Journal for Science and Engineering*, 43(8), pp. 4085-4104.

**DOI / official publisher:** https://doi.org/10.1007/s13369-017-2777-7

**Project relevance:** Security and optimization help distinguish benign transform robustness from deliberate removal resistance.

**Implementable gap:** Use keyed/seeded embedding and add combined or adaptive attacks; the current matrix tests isolated transforms with a fixed payload.

## Sharma et al. (2017)

**Citation:** Sharma, R., Gupta, A. K., Singh, D., Verma, V. S. and Bhardwaj, A. (2017) 'A robust image watermarking in contourlet transform domain', *AIP Conference Proceedings*, 1897, article 020014.

**DOI / official publisher:** https://doi.org/10.1063/1.5008693

**Project relevance:** A multiscale directional transform is a useful alternative to DCT for testing crop and rotation sensitivity.

**Implementable gap:** Add contourlet, or a clearly documented multiscale substitute if contourlet tooling is unavailable, and retain the same images, attacks, BER, and quality metrics for a controlled comparison.
