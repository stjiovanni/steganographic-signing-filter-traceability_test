# Tang et al. (2019) - Robust Image Hashing

**Harvard reference:** Tang, Z., Chen, L., Zhang, X. and Zhang, S. (2019) ‘Robust image hashing with tensor decomposition’, *IEEE Transactions on Knowledge and Data Engineering*, 31(3), pp. 549–560.

**DOI:** https://doi.org/10.1109/TKDE.2018.2837745

**Official record:** https://ieeexplore.ieee.org/document/8360464

**Use in FPR:** Supports transformation-tolerant perceptual hashing as a similarity signal. The tensor-decomposition hash is not implemented locally.
